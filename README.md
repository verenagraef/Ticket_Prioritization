## Source dataset

The validated source dataset is included in this repository at:

```text
data/raw/aa\\\_dataset-tickets-multi-lang-5-2-50-version.csv
```

The source dataset is the **Customer IT Support - Ticket Dataset** by **Tobias Bueck**, redistributed under the **Creative Commons Attribution 4.0 International (CC BY 4.0)** license. Dataset attribution, source information, redistribution terms, and the distinction between the source data and the derived prepared dataset are documented in `DATASET\\\_LICENSE.md`.

Citation of the Dataset: Tobias Bueck. (2025). Customer IT Support - Ticket Dataset \[Dataset]. Kaggle. https://doi.org/10.34740/KAGGLE/DSV/13959267

The analysis scripts validate the raw-file identity before continuing. The repository's MIT license applies to original repository code only and does not replace the dataset's CC BY 4.0 license.

## Environment

Create the environment from the repository root:

```bash
conda env create -f environment.yml
conda activate masterthesis\\\_final
python -m nltk.downloader stopwords
```

The analysis was finalized on **Windows x86-64** with Python 3.11.15 and pinned analytical package versions in `environment.yml`. The environment therefore contains Windows-specific Conda runtime packages in addition to the pinned analytical Python stack.

Externally hosted pretrained models are also pinned in the code:

* Sentence Transformer for semantic grouping: `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`
* multilingual DistilBERT screening: `distilbert/distilbert-base-multilingual-cased`
* sentiment model: `cardiffnlp/twitter-xlm-roberta-base-sentiment`

The sentiment model and the two Hugging Face grouping models use explicit repository revisions in the final scripts.

## Execution order

Run the scripts from the repository in this order:

```text
01\\\_data\\\_understanding.py
01a\\\_manual\\\_review\\\_validation.py
02\\\_data\\\_preparation.py
03a\\\_algorithm\\\_screening\\\_explorativ.py
03b\\\_representation\\\_screening\\\_explorativ.py
03\\\_modeling.py
04\\\_evaluation.py
05\\\_explainability.py
05a\\\_knn\\\_shap\\\_sensitivity.py
06\\\_integrity\\\_audit.py
```

### Stage roles

* **01**: Data Understanding, language audit, semantic embeddings, deterministic review templates.
* **01a**: validates and consolidates the three frozen author reviews.
* **02**: Data Preparation, exclusions, language corrections, text normalization, exact and semantic grouping.
* **03a**: exploratory training-only algorithm screening.
* **03b**: exploratory training-only Word/Character TF-IDF representation screening.
* **03**: final five-fold group-aware Modeling, hyperparameter selection, feature-set comparison, OOF predictions, and final model fitting.
* **04**: fixed hold-out Evaluation and group-aware paired bootstrap inference for H1.
* **05**: SHAP-based Explainability and H2 analysis on the frozen post-selection design.
* **05a**: kNN Permutation-SHAP sensitivity analysis for background size and permutation budget.
* **06**: deterministic final integrity audit of the complete Analysis.



## Reproduction

To test a reproduction from source, keep:

1. the source code under `src/`;
2. `environment.yml`;
3. the raw dataset at `data/raw/aa\\\_dataset-tickets-multi-lang-5-2-50-version.csv`;
4. the three `\\\*\\\_AUTHOR\\\_CONFIRMED.csv` Data Understanding review files;
5. repository-level license/citation documentation;
6. optional paper/LaTeX files.

Do not rename internal folders such as `src`, `data`, `reports`, `cache`, or `models` without updating the scripts.
